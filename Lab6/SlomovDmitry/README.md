# Лабораторная работа 6: сетевое взаимодействие

Дмитрий Сломов, группа 4140.

## Запуск

Открыть `ITMO-proj.xcodeproj` в Xcode 26.2 или совместимой более новой версии.
Дождаться загрузки Alamofire через Swift Package Manager, выбрать схему `ITMO-proj`
и iPhone Simulator. Нажать Run, затем в меню открыть «Lab 6: Сеть».
Версия Alamofire зафиксирована: 5.10.2. SwiftData и предыдущие лабораторные для запуска не требуются.

## Выполнено

- GET `/posts` и POST `/posts` к JSONPlaceholder.
- Кодирование тела POST в JSON и декодирование ответа в Swift-модели.
- Нормализация текста, сортировка публикаций и подсчёт слов.
- Обработка ошибок соединения, HTTP-статуса и декодирования с сохранением error/code/data.
- Проверки HTTP 404 и несовпадения структуры JSON доступны кнопками на экране.
- Обработка ответа и данных в фоновой очереди GCD; обновление UI на главной очереди.
- Разделение MVVM, сетевой клиент, сервис операций и отдельный обработчик данных.

JSONPlaceholder имитирует создание записи: POST возвращает результат, но не сохраняет его для следующего GET.

## Проверка

В архиве сохранены два unit-теста обработки данных и два UI-теста перехода и счётчика.
Запуск в Xcode: Cmd+U. Автоматические тесты не обращаются к реальному API.
Структура проекта и зависимости проверены статически. В среде подготовки нет Xcode,
поэтому сборка и XCTest здесь не запускались.
