# Лабораторная работа 4

Дмитрий Сломов. Самостоятельный Xcode-проект для проверки этой лабораторной.

## Реализация

Приложение заметок с MVVM и двумя инструментами хранения:

- SwiftData хранит заметки: текст и дату создания. Реализованы добавление, чтение, изменение и удаление.
- UserDefaults хранит небольшую настройку `lab4.showDates`: показывать ли даты. Настройка создаётся/изменяется переключателем, читается при открытии, удаляется кнопкой Reset settings.

Заметки и настройка должны сохраняться между запусками приложения. SwiftData подходит для набора редактируемых записей, UserDefaults — для одного небольшого параметра интерфейса.

`Lab4Note` — модель данных; `Lab4ViewModel` выполняет операции хранения; `Lab4View` показывает список и редактор. Контейнер SwiftData подключён в `ITMO_projApp`, контекст передаётся из окружения. Редактор хранит отдельный черновик: Cancel не изменяет заметку. Ошибки сохранения выводятся на экран, незаписанные изменения откатываются.

## Запуск

1. Открыть `ITMO-proj.xcodeproj` в Xcode 26.2 или новее.
2. Выбрать схему `ITMO-proj` и конкретный iPhone Simulator с iOS 26.2 или новее.
3. Запустить через Cmd+R. Для симулятора выбор Personal Team не требуется.

Проект использует Swift language mode 5. На физическом устройстве требуется выбрать собственный Team в Signing & Capabilities.

## Проверка

Добавить две заметки, отредактировать одну, проверить Cancel и удалить другую. Выключить показ дат, остановить приложение и снова запустить в том же симуляторе: заметка и настройка должны сохраниться. Reset settings возвращает показ дат и удаляет сохранённый ключ. Проверить удаление после повторного запуска.

В этой подготовке проверены состав файлов, относительные ссылки проекта и соответствие исходников заданию. Сборка в Xcode и запуск в симуляторе после выделения отдельного проекта здесь не выполнялись.

Тестовые targets сохранены из исходного проекта. Они содержат шаблонные тесты; покрытия логики этой лабораторной пока нет.
