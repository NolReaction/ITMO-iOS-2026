# WatchNext: фильмы и сериалы

Дмитрий Сломов, группа 4140.

Полное приложение из предоставленного проекта: лабораторные 1-6 и WatchNext.
Исходные Swift-файлы приложения и тестов сохранены без изменений.

## Запуск

Открыть `ITMO-proj.xcodeproj` в Xcode 26.2 или совместимой более новой версии.
Дождаться загрузки Alamofire 5.10.2, выбрать схему `ITMO-proj` и iPhone Simulator.
Нажать Run. В главном меню выбрать «WatchNext: Фильмы и сериалы».
Предыдущие лабораторные доступны в том же меню.

## Возможности WatchNext

- Поиск фильмов и сериалов и загрузка каталога через API ПоискКино.
- Сеть через URLSession, async/await и actor WatchNextAPI.
- Проверка HTTP-статуса, обработка ошибок сети и JSON.
- Карточка фильма с описанием, жанрами, рейтингом и постером.
- Личный список в SwiftData, статусы просмотра и скрытие просмотренного.
- Случайный выбор фильма на вечер из запланированных с фильтром по жанру.
- Настройки через AppStorage/UserDefaults, ключ API через Keychain.
- MVVM, отдельные модели ответа API, модели приложения и сохраняемые записи.

## Ключ API

Для каталога и поиска нужен собственный ключ ПоискКино.
В приложении открыть настройки кнопкой справа вверху, ввести ключ и сохранить.
Ключ хранится в Keychain на устройстве и не включён в репозиторий.
Личный список и выбор на вечер работают с уже сохранёнными данными.
Alamofire используется в Lab6; WatchNext обращается к серверу через URLSession напрямую.
