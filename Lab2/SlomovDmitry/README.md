# Лабораторная работа 2

Дмитрий Сломов. Самостоятельный Xcode-проект для проверки этой лабораторной.

## Реализация

Два экрана на SwiftUI. Первый показывает число и две кнопки: генерация случайного числа от 1 до 100 и переход на второй экран.

`@State` хранит число для первого экрана. `NavigationStack` в `ContentView` обеспечивает навигацию и кнопку возврата; `NavigationLink` открывает второй экран.

## Запуск

1. Открыть `ITMO-proj.xcodeproj` в Xcode 26.2 или новее.
2. Выбрать схему `ITMO-proj` и конкретный iPhone Simulator с iOS 26.2 или новее.
3. Запустить через Cmd+R. Для симулятора выбор Personal Team не требуется.

Проект использует Swift language mode 5. На физическом устройстве требуется выбрать собственный Team в Signing & Capabilities.

## Проверка

Нажать Generate number: число должно быть в диапазоне 1...100 (оно может повториться). Открыть второй экран и вернуться назад: число сохраняется.

В этой подготовке проверены состав файлов, относительные ссылки проекта и соответствие исходников заданию. Сборка в Xcode и запуск в симуляторе после выделения отдельного проекта здесь не выполнялись.

Тестовые targets сохранены из исходного проекта. Они содержат шаблонные тесты; покрытия логики этой лабораторной пока нет.
