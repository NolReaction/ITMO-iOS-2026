# Лабораторная работа 3

Дмитрий Сломов. Самостоятельный Xcode-проект для проверки этой лабораторной.

## Реализация

Генератор случайного числа с архитектурой MVVM:

- Model: `NumberGenerator` задаёт диапазон и генерирует число.
- ViewModel: `RandomNumberViewModel` хранит состояние и обрабатывает действие генерации.
- View: `Lab3View` отображает число и вызывает метод ViewModel при нажатии кнопки.

MVVM выбран для отделения логики генерации и состояния от разметки SwiftUI. `@Published` сообщает об изменении числа, а `@StateObject` сохраняет объект ViewModel при обновлениях экрана. ViewModel изолирована главным актором через `@MainActor`.

Для кнопок использованы системные стили Liquid Glass: `.glassProminent` и `.glass`.

## Запуск

1. Открыть `ITMO-proj.xcodeproj` в Xcode 26.2 или новее.
2. Выбрать схему `ITMO-proj` и конкретный iPhone Simulator с iOS 26.2 или новее.
3. Запустить через Cmd+R. Для симулятора выбор Personal Team не требуется.

Проект использует Swift language mode 5. На физическом устройстве требуется выбрать собственный Team в Signing & Capabilities.

## Проверка

Нажать Generate number, перейти на второй экран и вернуться назад. Число должно обновляться по кнопке и сохраняться при возврате. Проверить разделение кода на Models, ViewModels и Views.

В этой подготовке проверены состав файлов, относительные ссылки проекта и соответствие исходников заданию. Сборка в Xcode и запуск в симуляторе после выделения отдельного проекта здесь не выполнялись.
