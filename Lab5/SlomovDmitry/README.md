# Лабораторная работа 5

Дмитрий Сломов, группа 4140. Самостоятельный Xcode-проект на основе Lab4.

## Реализация

Экран Lab5 анализирует сохранённые заметки Lab4: считает количество заметок, слов и символов с пробелами. Используется MVVM.

- `Lab5ViewModel.loadNotes` читает заметки через SwiftData на главном акторе и формирует снимок текстов `[String]`.
- `Lab5ViewModel.analyzeNotes` запускает расчёт через `DispatchQueue.global(qos: .userInitiated).asyncAfter`.
- `Lab5NoteAnalyzer` считает статистику в фоне и возвращает `Lab5Statistics: Sendable`.
- `DispatchQueue.main.async` публикует результат и обновляет интерфейс.
- `Thread.isMainThread` показывает, где выполнен расчёт и где получен результат.
- Переключатель «Учебная задержка: 2 секунды» откладывает начало работы без блокировки потока. Задержка помогает показать отзывчивость UI; сам подсчёт небольшого числа заметок выполняется быстро.

Объекты SwiftData и `ModelContext` не передаются в фоновую очередь. Анализ работает со снимком строк, сделанным в момент запуска. Пока операция идёт, повторный запуск и переход к редактору заблокированы; отдельная кнопка счётчика нажатий остаётся активной.

## Состав проекта

Четыре исходных файла Lab5 сохранены из предоставленного архива без изменений. В проект включены `Lab4Note`, `Lab4ViewModel` и `Lab4View`, поскольку Lab5 читает их заметки и открывает редактор. SwiftData-контейнер для `Lab4Note` подключён в `ITMO_projApp`.

`ContentView` открывает `Lab5View` внутри `NavigationStack`. Bundle ID приложения — `com.slomov.itmo.lab5`, поэтому отдельная сборка Lab5 имеет своё хранилище: заметки из отдельно установленного приложения Lab4 автоматически не переносятся.

## Запуск и проверка

1. Открыть `ITMO-proj.xcodeproj` в Xcode 26.2 или новее.
2. Выбрать схему `ITMO-proj` и iPhone Simulator с iOS 26.2 или новее.
3. Запустить приложение через Cmd+R. Для симулятора Personal Team не требуется.
4. Нажать «Открыть заметки Lab4», создать несколько заметок и вернуться на экран Lab5.
5. Включить учебную задержку и нажать «Посчитать статистику».
6. Пока ожидается результат, нажимать кнопку счётчика: интерфейс продолжает отвечать.
7. Проверить статистику: поток расчёта — «Фоновый», поток показа результата — «Главный».
8. Отключить задержку и повторить расчёт. Результат должен совпасть.

На физическом устройстве необходимо выбрать собственный Team в Signing & Capabilities.
